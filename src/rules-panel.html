Rules

Standing instructions for this studio and the current session.

  1. Record every task

    Pass each requested task to Task Keeper so it appears on the task list.

  2. Start small tasks promptly

    The coordinator may take small or early tasks immediately while keeping the task record current.

  3. Reuse the named agents

    Keep persistent agents with readable names. Give them concise context when assigning or handing off work.

  4. Keep the repository clean

    Exclude generated artifacts, dependencies, stale files, and local runtime records from commits.

  5. Leave the Vercel deployment alone

    Keep the existing remote Vercel deployment untouched unless a change is explicitly requested.

  6. Verify the live monitor

    The coordinator must personally verify the monitor daemon and real WebSocket evidence before reporting live monitoring as working.

  7. Preserve generation settings

    Keep the requested settings in model comparisons. Do not reduce precision or steps without being asked.
